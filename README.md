# 悉尼空气质量预测系统  
![Project Banner](https://www.environment.nsw.gov.au/sites/default/files/2024-07/sydney-skyline-124278.jpg)  

## 🚀 核心功能  
- 实时抓取NSW空气质量数据  
- 机器学习预测PM2.5峰值  

## 🛠️ 技术栈  
- Python 3.10  
- Scikit-learn  
- GeoPandas  

## 📊 数据源  
[NSW Government Open Data Portal](https://www.airquality.nsw.gov.au/air-quality-data-services/data-download-facility)
